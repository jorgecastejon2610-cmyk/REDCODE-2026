## Resumen Ejecutivo

Este repositorio contiene la documentación técnica, el esquema de montaje de LEGO, el código fuente y la pista de prueba ejecutada por el equipo REDCODE para participar en la categoría Futuros Ingenieros de WRO 2026.

El robot es un vehículo autónomo LEGO impulsado por la placa BBC micro:bit sobre una plataforma de chasis modular. La estructura tiene cuatro ruedas distribuidas en dos pares, utilizando las ruedas delanteras para el manejo direccional y las traseras para la propulsión y el manejo hacia atrás.
